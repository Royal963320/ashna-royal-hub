# ROYAL HUB

Premium, mobile-first marketplace homepage built with Next.js, TypeScript and CSS.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Current scope

- Responsive premium Royal Gold + Black homepage
- Hero, category cards, featured product cards and trust section
- Ready for the next phases: Supabase catalog, product details, checkout and Razorpay test-mode integration

Development branch: `feature/royal-hub-homepage`
